# E-commerce Conversion Funnel Dashboard

## Project Overview

This project analyzes user behavior in an online store and identifies where users drop off within the conversion funnel.

## Business Goal

Help marketing teams identify conversion bottlenecks and optimize customer journeys.

## Tools

- BigQuery
- SQL
- Tableau Public

## Key Metrics

- Total Sessions
- Orders
- Conversion Rate
- Revenue

## Key Findings

- Significant user drop-off occurs before the product view stage.
- Additional losses occur between product view and add-to-cart.
- High-volume traffic channels show lower conversion rates.
- The "Unknown" traffic category demonstrates higher conversion but requires data quality investigation.

## Recommendations

- Improve landing page relevance.
- Optimize traffic acquisition channels.
- Validate tracking and channel attribution.
- Conduct A/B testing of product pages.
